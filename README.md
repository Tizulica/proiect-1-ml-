# proiect-1-ml-
Project 1 - Machine Learning IT School
1. Explorați datele: dimensiune, valori lipsă, distribuția coloanei de prezis, 3 grafice cu
câte o propoziție despre ce se vede.
E clasificare sau regresie? Ce greșeală a modelului ar costa mai mult în realitate?
2. Pregătiți datele: împărțire train/test, valori lipsă, coloane text transformate în numere,
scalare dacă e nevoie.
De ce împărțim datele înainte de scalare?
3. Baseline: DummyClassifier sau DummyRegressor .
Ce scor are un model care nu știe nimic?
4. Antrenați cel puțin 2 modele din cele făcute la curs: regresie liniară sau logistică,
arbore de decizie, Random Forest, XGBoost, SVM.
Care a ieșit mai bine și de ce credeți că s-a întâmplat asta?
5. Evaluați pe setul de test: la clasificare matrice de confuzie, precision, recall, F1; la
regresie MAE, RMSE, R².
De ce ați ales metrica principală pe care ați ales-o?
6. Concluzie: ce model recomandați, cât de mult bate baseline-ul și o limitare a analizei.
